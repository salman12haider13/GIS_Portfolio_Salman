01 Spatial analysis
Open map Open map

Where could a new Calgary park improve access most?

I mapped 15-minute walking access to community parks, then combined the service gaps with population and Pampalon social-deprivation data. An equity-weighted location-allocation model identified a candidate site where a new park could improve access for underserved residents. The result is a defensible planning starting point—not a final decision—because land availability, growth, and community input still matter.

ArcGIS Pro · Network Analyst · Service areas · Location-allocation · Equity weighting

02 GIS automation

Can natural language become reliable GIS automation?

For my MGIS capstone, I built an ArcGIS Pro script tool that converts plain-language requests into controlled, inspectable geoprocessing workflows. Tested across 36 scenarios, the strongest GPT-based workflow achieved 91.7% function-selection accuracy and 83.3% parameter accuracy. The result demonstrates both the potential of language-assisted GIS and the importance of validation, explicit tools, and transparent execution.

ArcGIS Pro · ArcPy · GPT-5 · Llama 3.1 · Workflow validation
